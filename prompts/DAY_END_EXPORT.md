# 日终默认深入复盘与可下载结转

用户说“结束今天”，或今日实际活动已到预算/题源边界时，先默认给完整复盘，不能只询问要不要总结。未完成七族、讲解、专项或验收时，明确列为未完成；不得为漂亮日报补造作答。

复盘必须能独立阅读：

1. 当日计划与真实作答题目/版本、每子问暂定分与待复核分母、首答完整性及提示情况。
2. 每题第一处可靠断点、会做的正证据、错误传播与 R/T/M/C/F 机制；未知错误定位明确写未知。
3. 涉及的知识与题型、关键原理、选法依据、适用条件、典型误用/反例、代表性逐式解法与独立核算。
4. 高数/线代及七族的计划、实际展示、真实作答、反馈和修复状态；未覆盖者单列，不以元数据标签替代。
5. 难度结构锚定/校准状态、真实时间证据及 null 项，尤其区分活动窗口与净作答；不得伪造时间总和。
6. 实际专项步骤、本人回答、仍未掌握部分、新结构候选验收结果与缺题缺证据。
7. 真实 D0/迟测候选及到期任务、次日优先级和预算竞争；没有已发生的事件不虚构日历通过。
8. 形成性阅卷、附件缺失、版本风险、整包曝光和正式考试冻结等边界。

随后提供可以用文字选择的后续行动：“继续深分析”“继续未完成专项”“追加 R2 迁移”“可选 R3 综合”“结束并结转”。选择后必须实际展开相应分析、当前专项互动或合格新题，不能只生成一份提示词；R3 条件或题源不足时明确拒绝加难并说明缺口。额外深化不抹掉已经完成的默认复盘。

## 结课导出

直接以教练包中的 DAILY_RETURN_TEMPLATE.json 为骨架填真实发生的内容，并用包内 Schema 自检。release_id、source_state_hash、item_version 逐字复制，不重算/改写源状态。record_kind 按本轮真实训练或明确模拟而填，不能将演示改成 REAL。

在当前会话工具确实支持时，生成并提供以下真实可下载附件，再合并成 DAILY_RETURN_YYYYMMDD.zip：

- DAILY_RETURN_YYYYMMDD.json：严格符合包内 Schema 的主结转。
- DAILY_REVIEW_YYYYMMDD.md：上方完整深入复盘。
- ATTEMPT_EVENTS_YYYYMMDD.jsonl：主结转 attempts 数组按原对象逐条投影，一行一条；不另造首答。
- SPECIALTY_STATUS_YYYYMMDD.json：主结转 repair_events 的真实事件投影。
- EXPOSURE_DELTA_YYYYMMDD.json：presented_items 保守曝光投影。
- RETEST_DELTA_YYYYMMDD.json：retest_events 真实训练或候选事件投影。
- 能实际导出的原始答卷附件：仅使用安全相对路径，并在主结转 assets 中引用真实路径/哈希。

读回刚生成的 JSON/JSONL/ZIP 再检查：文件存在、可解压、JSON 可解析、ID/版本可引用、没有重复首答、分项分母一致、未知时间为 null、原答未被补交覆盖。只有真实执行过的检查才能报告结果；没有 Schema 工具时写“未运行机器 Schema 校验，待离线导入器复核”，不能自报 PASS。

如果当前会话不能创建下载文件或 ZIP，明确写“附件/ZIP 未生成”，给出完整 JSON/Markdown/JSONL 内容及准确保存文件名；不能编造下载地址、占位空附件或说已持久化。该情况是文件交付降级，应保留可转交的实际内容，不能假装完整链路已通过。

学生只需下载本次结转并在下一次交给 Codex/构建器；学生无需运行命令。离线构建器负责 Schema、引用、真实附件字节、历史去重、曝光和时间证据校验，再追加历史、生成下一日两个 ZIP。不在 ChatGPT 内声称已经修改 GitHub、合并真实历史或成功调用未提供的系统。

新会话必须重新读取当天包和最近一次经校验的状态，不能保证靠聊天记忆延续。缺昨日结转时标明使用的是已有状态，不自称已经按昨日表现更新。公开仓库只放中性模板与允许公开的代码/题源；私人答卷、成绩和真实状态按用户授权另存。

## 完整性与日终深复盘

逐项列出：七族实际展示/提交、具体子问对应节点、未测节点；本日巩固、错因修复已确认、陌生新题独立通过、跨日稳定通过四类证据；逐题已会步骤/第一错/最短纠正；概念新知及未验证部分；已执行专项与未执行建议；自报活动时间、计时窗口和未知净时长；已知阅卷错误及所有修订；次日优先级。

导出 JSON/MD/ZIP 后必须实际读回，检查题号、版本、答卷覆盖、日期、Schema及附件真实字节。reported_answered_item_ids 列出真实声称已答题，不能只导出前两题冒充整日完整。缺原照写 SOURCE_NOT_ATTACHED；只有二级报告则导出 REPORTED_SESSION，状态 PARTIAL_STATE_ONLY，不把摘要填进首答。release_date 保存原发布日，date 为实际训练日，source_state_hash 保持原样。

180分钟整卷只有在真实整组、零提示、计时齐全和曝光合格时才评估；客观80与解答70分别统计，日常70分不能外推150或稳定120。
