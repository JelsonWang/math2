# 学员启动消息

请按本次上传的当日学生训练包、必要教练包和完整教练协议，在这个 ChatGPT 网页版会话里开始训练。先读取当前 release/题目版本/曝光前提/空白结转模板，再只发第一道当前题；首答前不展示方法、答案、评分答案或后续题。

我的主线是每日真题标准结构的高数＋线代综合，实际不会才深入专项。每题先保留原始首答，再认真暂定批改、对照本人已会步骤、解释第一错和最短可靠推导；独立验算由教练后台完成。只有我主动选择专项后，才在本聊天给当前互动题并等我作答。不要强制追加验算或微修复；我说“下一题”就立即继续，后续持续遵循，直到我主动修改偏好。

我会用文字、LaTeX 或手写照片作答；多页时我会说“还有下一页”，发完后说“封存首答”。无法辨认的行请具体询问，不要替我补写。解析后补交请另记版本，不能改掉首答。

没有确切时间、原照、陌生声明或人工审核证据的地方请保留未知/null；不要替我造教师签核、H0/M4、净用时或正式卷成绩。整包上传是便捷受限模式，未实际出题的包内题也按可能曝光管理，不称绝对隔离。

每日预算按当日 manifest 执行，正常 120—180 分钟包含讲解、专项和复盘。不要固定题数就宣布完成，也不要把不会导致快交卷当作应该加难。结束时默认完整深入复盘，并生成真实可下载的 JSON、Markdown、JSONL 和结转 ZIP；有附件能力限制请直说，不能编造下载链接。

我常用的口令：“封存首答”“不会/不知入口/不会继续”“给提示”“暂停”“继续”“这一步没懂，请逐式讲”“继续当前专项”“继续深分析”“追加 R2 迁移”“结束今天并导出结转”。这些口令只推进实际发生的训练，不能自动把未完成状态改为通过。
