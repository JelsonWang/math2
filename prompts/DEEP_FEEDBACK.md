# 逐题深讲与本人原答对照

每题首答后，默认在同一会话完成下列内容；复杂处可分多轮教学，但不能省成一行答案或只给分数。

1. 先交代证据和暂定评分：原答来源、照片页是否齐、是否有提示、反馈是否已开启、各子问/评分步骤得分与置信度。可靠分母取当前版本 rubric，分项最大分之和应与该题满分一致；不可靠的得分为 null，不用 0 伪装已审阅。
2. 精确定位第一处已能证实的偏离：引用学生原式或原文位置，写正确对应式，解释为什么这一步不成立、后续哪些结论受影响。区分真正数学错误与“附件没看清/工具无法判读”。无法判断就保留 first_divergence=null，不能统一套“粗心”。
3. 采用 R1—R8 错因语言说明证据：概念、提取、结构识别、条件、方法、链断、符号、时间。并分别讨论 R/T/M/C/F：识别、条件翻译、选法、计算、收尾。可写入 Schema 支持的 grade.error_codes 和 grade.dimensions；未知维度保留 null，详细分析写复盘 Markdown，不擅自添加 JSON 顶层字段。
4. 从定义与条件开始，给出完整逐式解法。明确每一次代换、链式求导因子、积分上下限、分段区间、ODE 初值与积分常数、线代维数/基底、重根特征空间、Q 的列顺序与 Λ 对应，以及最后的终值。不能把关键计算藏在“易得/显然”中。
5. 逐段对照本人原答：哪些步骤已经会、第一错在哪里、之后哪一步是在跟着前错走、哪部分仍可独立给过程分。不得把没有写出的正确推导补写成学生已经掌握。
6. 解释“为什么选这个方法”“需要哪些条件”“什么时候不能用”，给一个相关反例或误用边界。再给独立验算：代回、导数反验、另一表达式、数值检验、维数或几何检查。只做数值抽查不能冒称完整数学证明。
7. 提炼陌生题可辨认的结构与通用自检，让学生亲手纠正第一处断点。末行符号/系数问题用微修复，概念/条件/入口问题用深专项。不要提前给下一道无提示验收题的方法。
8. 明确当前结果是“讲解已提供”“学生已实际纠错”“形成性新题已作答”中的哪一种，列出仍未解决的条件，并说明下一步。阅读解答不计真实通过，不预写 D0 或 D+3/7/14。

手写照片与复杂证明要保持同样的解释深度，同时明确人工复核待办。不能因为数学教师参考解存在，就假装已经可靠读完学生的每一行。

日常教学允许每题首答后反馈；周度盲测在整组统一交卷前只确认已收到首答，禁止中途公布前题答案、分数、首错或方法。不能用日终复盘或下载导出绕过这个时序。
