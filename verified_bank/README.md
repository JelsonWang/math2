# 私有本地题库

公开仓库只包含通用构建、数学校验和文件规则。实际题面、未曝光新题、教师答案、原始十表和 PILOT 学习历史留在本机的两个文件：

- `private_catalog.json`
- `private_catalog.manifest.json`

这两个文件必须通过 `.gitignore` 排除；任何公开发布流程都应再次检查暂存区与 Git 历史。不要将它们复制到公开示例或测试快照。私有发布 ZIP 可以向资料所有人交付，但必须与公共 GitHub 代码包区分。

从本次本地交付或用户自己的受控备份恢复两个文件后，可以离线运行 `python -m math2_pack validate`。也可通过命令支持的 `--bank` 参数指向其他本地私有路径。缺文件时工具明确报 `MissingPrivateBank`，不会自动下载、生成真实成绩或用空题库假装完成。

私有文件包含 293 条原题候选和 21 道本地形成性题，以及 67 节点的真实名称/模块元数据。原 190 道 Tier2 和其他未完成当前完整审核的旧题保持冻结。新题也只具有有限符号核验，不是经过真人审校或实测校准的真题难度认证，不能自动授予 H0/M4。

67 节点对外投影只含编号、名称、模块和能力族，不携带旧成绩、掌握状态、答卷指针或学习历史。PILOT 摘要与原始十表仅保存在私有文件中。

`private_catalog.manifest.json` 是精确字节及载荷哈希清单，并非教师签名。改题面、推导、答案、评分、提示或来源后，原清单会失败并冻结候选题。重新生成哈希不等于数学 QA 或真人审核；真正修改内容后仍必须运行独立模型校验并由资料所有人安排必要审阅。

ChatGPT 网页版是唯一训练入口。学生与教练文件持有人可以打开文件，不能将 ZIP 或聊天规则称为绝对物理保密。一次只呈现当前题、真实曝光登记、暂定评分和不可变首答规则仍须由运行协议明确执行。
